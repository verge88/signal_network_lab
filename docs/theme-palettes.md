# Палитры «Графит» и «Фарфор»

Переключение: **Вид → Тема**. Образцы, копирование HEX-кодов и всей палитры: **Вид → Палитра оформления…**. В этом окне переключатель меняет только просмотр; «Применить тему» сохраняет выбранное оформление программы.

Цвета адаптированы для нативных форм, графиков и схем. За ориентир взяты официальные палитры [Dark](https://github.com/microsoft/vscode/blob/main/extensions/theme-defaults/themes/dark_vs.json) и [Light](https://github.com/microsoft/vscode/blob/main/extensions/theme-defaults/themes/light_vs.json). Источник цветов приложения — `native/theme_palettes.py`; его же использует загрузочный экран без загрузки вычислительных модулей.

Три прежние темы сохранены. Pure Black остаётся темой по умолчанию. Палитра приложения не меняет отдельно настроенное оформление экспортируемых файлов.
