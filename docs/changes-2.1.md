# Изменения 2.1 и покрытие запроса

| Приоритет | Реализовано | Граница покрытия |
|---|---|---|
| Транзакции | request/answer, session/transaction ID, точные таймеры, повторы, кэш дубликатов, обратный трафик, auth → registration, состояние абонентов | Выбранные абстрактные процедуры; нет полного MAP/TCAP/ISUP стека |
| Маршрутизация | PC, таблицы next hop, GTT-префиксы, realm/host/application, RC, состояния ASP/peer, распределение по абонентам | Состояния управления задаются параметрами; нет полных автоматов CER/CEA, watchdog, ASPUP/ASPAC |
| Отказы | Физический отказ отдельно от обнаружения/переключения, направления, короткие обрывы, рестарт с очисткой состояния, прерывание очереди и обработки, плавный допуск после восстановления | Время обнаружения задаётся; heartbeat-пакеты не моделируются |
| Транспорт | Фрагменты, ACK, повторы, RTT/RTO, окно, упорядочивание по потокам, параллельные пути, конечные буферы, серии потерь и асимметрия | Упрощённая модель, без полного SCTP SACK/TSN и стандартного congestion control |
| Узлы | Параллельные обработчики, общий предел допуска, приоритетные очереди, распределения времени, стоимость операции, промахи кэша/задержка БД, ошибки | Нет отдельного пула соединений БД, реальных БД и подробных vendor overload policies |
| Абоненты | Группы, периодический профиль и всплески, распределение размеров, последовательность auth/register, причинные повторные запросы после сбоев | Нет географии, handover/mobility и полной модели жизненного цикла абонента |
| Метрики/ML | p99, незавершённые процедуры, повторы, причины ошибок, направления, восстановление, throughput без хвоста, независимый reservoir, три вида меток, защита совместимости v1/v2 | Экспозиция события и наблюдаемое ухудшение не доказывают причинность |
| Калибровка | CSV измерений, подбор на train, отложенные run_id, ошибки/распределения, применение конфигурации и JSON-отчёт | Реальные измерения не предоставлены; сходство с оборудованием не подтверждено |

Нативный интерфейс Qt и тема Pure Black сохранены. Расширенные параметры открываются из инспектора. Телеметрия включает вкладки транзакций, состояний, процедур, транспорта и пар запрос/ответ.

Прежний движок доступен в Экспериментах как «Отдельные сообщения · v1». Новые поля в нём не меняют физику. Открытие старого проекта без `engine` выбирает новый режим процедур; для воспроизведения старого расчёта явно выберите v1 и примените параметры. Старые записи результатов и обученные артефакты не переписываются.
