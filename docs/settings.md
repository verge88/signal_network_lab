# Настройки программы · 2.20.0

Нажмите **Настройки** внизу левого меню или **Правка → Настройки программы…**. Быстрое сочетание — **Ctrl+,**. В свёрнутом меню используется значок шестерёнки с подсказкой. Изменения применяются сразу; отдельная кнопка «Применить» не требуется. Параметры сохраняются для следующих запусков.

## Оформление

- **Тема** — пять существующих тем, включая чистую чёрную, светлую монохромную, Графит и Фарфор. Изменение синхронизируется с меню **Вид → Тема** и оформлением карты и диалогов.
- **Палитра цветов** — окно с цветами Графита или Фарфора, копированием значений и выбором темы. Для остальных тем эта кнопка отключена.
- **Свернуть левое меню** — оставляет иконки с подсказками; также доступно через **Ctrl+B**.
- **Строка состояния** — нижняя строка с текущими сообщениями. Её скрытие не скрывает панель активного вычисления с прогрессом и отменой.
- **Показатели на топологии** — верхние карточки результатов; стандартное значение — выключены. Показатели телеметрии остаются доступными независимо от этого переключателя.
- **Высота блока показателей** — 125–480 px. Текущий размер, включая изменение перетаскиванием, синхронизируется с этим полем.

## Карта топологии

Сетка и подписи задержек можно скрыть независимо друг от друга. Это меняет отображение карты; узлы, каналы, задержки и результаты расчётов остаются прежними. Новые и повторно открытые схемы используют выбранные настройки. Оформление экспортируемой схемы задаётся отдельно в окне экспорта.

Скорость перемещения колёсиком задаётся от 0,25× до 4×, по умолчанию 1×. Шаг масштаба Ctrl + колесо — от 1,05× до 1,50× за деление, по умолчанию 1,15×. Shift + колесо перемещает по горизонтали; зажатое колесо либо Пробел с перетаскиванием позволяют свободно двигать карту.

Если отключить **Вписывать схему при переходе**, переход между вкладками сохраняет ручной масштаб и положение карты. Команда **Вся сеть** и Ctrl+0 продолжают работать. Начальная схема при создании окна вписывается автоматически.

## Запуск и поведение

Стартовая вкладка выбирается из всех восьми разделов, включая Настройки. Изменение действует при следующем запуске. По умолчанию открывается Топология.

**Запоминать размер и положение окна, ширину инспектора** управляет восстановлением и сохранением геометрии. Состояние развёрнутой топологии не становится отдельным окном программы.

**Восстанавливать последнюю рабочую схему** включает загрузку локального черновика, а при его отсутствии — последнего сохранённого проекта. Если отключить, следующий запуск начнётся со стандартного шаблона. Явно сохранённые проекты и результаты доступны в библиотеке. Рабочий черновик продолжает обновляться для текущей схемы; для отдельного хранения используйте **Сохранить проект**.

**Звуковой сигнал после успешного вычисления** по умолчанию отключён. При включении используется системный звук Qt после получения результата; ошибки и отмена не воспроизводят сигнал успешного завершения.

## Данные и экспорт

Папка данных показана только для чтения. Её можно открыть или скопировать путь. Здесь находятся библиотека исследований, обученные модели и диагностические журналы. Изменение места хранения через эту вкладку не выполняется: перенос рабочей базы во время расчётов требует отдельной процедуры. Для запуска из исходников или специального рабочего пространства остаётся параметр `--data-dir`.

Папка экспорта меняется выбором существующего каталога. Она также обновляется после сохранения через окно экспорта. Формат, DPI, цвета и подписи настраиваются непосредственно при экспорте. Отсутствующая папка при следующем запуске заменяется доступной стандартной папкой.

## Стандартные значения

Кнопка **Восстановить стандартные настройки** сбрасывает только перечисленные параметры программы и папку экспорта. Проекты, результаты, датасеты, модели ML, профили Linux-стенда, параметры калибровки и стили экспорта сохраняются. Старые настройки темы, левого меню и высоты верхнего блока подхватываются автоматически. Повреждённые значения заменяются стандартными.
